# Rhenus Group Clone

A pixel-faithful clone of [rhenus.group](https://www.rhenus.group) built with React + TypeScript + Vite + Tailwind CSS.

## Tech Stack

- **React 18** – UI framework
- **TypeScript** – Type safety
- **Vite** – Build tool & dev server
- **Tailwind CSS** – Utility-first styling
- **Lucide React** – Icons

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
